一、 核心物理規則 (Constraint Rules)
一行 15 字原則：除第一行標題外，所有行數寬度嚴格控制在 15 個中文字（含標點）內換行，避免手機端自動折行。

區塊化空行：標題、感言、特點、導流，這四大區塊之間必須強制空一行。

標點符號規範：全篇僅使用「，」、「！」、「。」。不使用問號「？」。

塊狀感言：感言部分禁止手動換行，必須形成一個連續的文字方塊。

二、 四大區塊結構定義 (Structure Definition)
1. 標題區 (The Golden Hook)
第 1 行 (硬資訊)：🍎 [ 物件名稱簡稱 ] 價格 (需含 🍎 圖樣)。

第 2 行 (吸引力)：由 AI 根據物件特色生成 15 字內精華。

第 3 行 (品牌定海神針)：固定內容 珍選好福邸｜三十年專業把關！ (不可更改)。

2. 感言區 (Professional Insight)
抬頭：✨ 房產三十年真心話：

內文：

限制：總字數約 60 字。

結構：3-4 句話組成。

要求：文字必須連貫、不可換行。內容需包含「專業判斷」與「價值導引」。

3. 特點區 (Core Values)
使用 ✅ 開頭，條列 3 個重點。

每行字數限 15 字內，嚴禁折行。

4. 導流區 (Call to Action)
指令：💬 想看內部影片或索取謄本

def generate_fb_post(object_name, price, main_feature, insight_topic):
    # 1. 標題區 (Hook)
    line1 = f"🍎 [ {object_name} ] {price}"
    line2 = f"{main_feature}" # 例如：三面曝光旺人潮！純商區聚財流
    line3 = "珍選好福邸｜三十年專業把關！"
    
    # 2. 感言區 (塊狀文字約60字)
    # 此處邏輯：根據 insight_topic 生成 3-4 句不斷句的文字
    insight_block = f"做生意位置決定一半勝負。這間角間店面三面招牌視野極佳！商業區定位清楚，經營節奏更好掌握。誠信服務，是我三十年不變的堅持！"

    # 3. 特點區
    features = [
        "✅ 角間三面曝光吸睛",
        "✅ 店住合一，自住自營",
        "✅ 純商業分區好規劃"
    ]

    # 4. 組合輸出
    post = f"{line1}\n{line2}\n{line3}\n\n"
    post += f"✨ 房產三十年真心話：\n{insight_block}\n\n"
    post += "\n".join(features) + "\n\n"
    post += "💬 想看內部影片或索取謄本\n"
    post += "點擊下方連結，語音諮詢福哥：\n"
    post += "👉 https://bit.ly/4sJhSzs\n\n"
    post += "👤 杜美珍 & 周福良 (福哥)\n"
    post += "📞 專線：0925-997779\n"
    post += "證號：(91) 登字第 010851 號"
    
    return post

四、 您需要提供給 AI 的「重點指令」
當您要生成新文案時，只需提供以下 4 個參數 給 AI 即可：

物件名稱：(例如：美崙角間店住)

價格：(例如：2100 萬)

一線重點：(例如：三面角間、純商區、人流大)

真心話主題：(例如：地段的重要性、創業的起點、投資的眼光)

💡 AI 生成時的「黃金 Hook」定義規則：
定義：利用「地點+稀有性+價格」組合。

選擇優先級：地點第一 > 稀有性第二 > 價格第三。

範例：🍎 [ 美崙角間店住 ] 2100 萬 遠比 🍎 [ 2100萬 ] 美崙店面 更有力，因為「美崙角間」是這間房子的靈魂。
